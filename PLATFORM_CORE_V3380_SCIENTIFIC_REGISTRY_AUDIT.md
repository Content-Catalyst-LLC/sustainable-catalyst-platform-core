# Platform Core v3.38.0 Audit

PASS criteria:
- scientific result identity is cross-domain;
- scientific artifact identity is content-addressed;
- source contracts and source object refs remain explicit;
- source payloads are referenced rather than duplicated;
- result, artifact and relation IDs are unique;
- relation endpoints must exist in the registry;
- typed result/artifact relations are supported;
- v3.37 statistical results can be registered;
- query filters are deterministic;
- snapshots bind exact registry fingerprints;
- portable registry packages validate selected identities;
- Core does not execute scientific methods;
- Core does not modify source artifacts;
- Core does not certify validity or truth;
- no database migration is introduced.
