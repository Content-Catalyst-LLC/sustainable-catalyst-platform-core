# Platform Core v3.42.0 Audit

PASS criteria:
- reproduction target binds exact source contract/object/fingerprint;
- plans require explicit verification criteria;
- exact hashes validate as SHA-256;
- numeric criteria require tolerances;
- evidence binds exact criterion identities;
- missing required evidence fails verification;
- advisory failures produce warnings;
- report result/evidence identities are unique;
- passed reports require all required criteria to pass;
- reproduction attempts bind exact plan fingerprints;
- comparisons bind known attempts/reports;
- expected/produced artifact and result presence is compared;
- equivalence is never declared without evidence;
- portable reproduction package binds plan/attempt/report/comparison fingerprints;
- scientific artifact bridge validates against v3.38;
- execution ownership remains Workspace/execution host;
- Core does not launch reproduction jobs or certify scientific validity;
- no database migration is introduced.
