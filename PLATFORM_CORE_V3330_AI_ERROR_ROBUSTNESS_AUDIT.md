# Platform Core v3.33.0 Audit

PASS criteria:
- failure taxonomy has stable versioned identity;
- observations bind exact model/evaluation/inference/evidence objects;
- suspected and confirmed causes remain distinct;
- evaluation slices and slice metrics are reproducible;
- robustness perturbations are explicit and hashable;
- baseline deltas and tolerance rules are first-class;
- robustness runs bind jobs and runtime environments;
- failure clusters remain descriptive;
- reports preserve limitations;
- Core does not autonomously diagnose causality;
- Core does not certify robustness or safety;
- no duplicate evaluation/inference storage is created;
- no database migration is introduced.
