# Platform Core v3.80.0 — Cross-Source Entity Reconciliation & Identity Provenance

Contract: `sc.core.cross-source-entity-reconciliation-identity-provenance.v1`.

This release reconciles source-specific identity observations across publications, datasets, registries, archives, public records, repositories, and knowledge bases while preserving provenance, temporal context, source independence, disagreements, and review state. Reconciliation remains a governed analytical handoff: source agreement, source count, and probabilistic linkage cannot establish canonical identity or mutate the identity graph.

Database migration: none.
