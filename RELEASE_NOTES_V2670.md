# Platform Core v2.67.0 — Visual Predictive Intelligence

v2.67.0 binds the complete Predictive Intelligence stack to the Visual Reasoning Runtime through provenance-aware visual predictive workspaces.

## Added
- forecast overlays across deterministic, probabilistic, and ensemble forecast evidence
- uncertainty and calibration displays
- ensemble/model-comparison visual bindings
- anomaly, change-point, and early-warning overlays
- spatial-temporal forecast layers
- causal/counterfactual predictive overlays
- predictive decision evidence bindings
- immutable SHA-256 chained visual predictive snapshots

## Boundary
Platform Core records and validates predictive visual semantics. It does not forecast, fit/calibrate models, combine ensembles, detect anomalies/change points, perform spatial prediction, execute counterfactuals, optimize decisions, render graphics, or infer truth from visual appearance.
