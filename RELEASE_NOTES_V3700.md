# Platform Core v3.70.0 — Graph Machine Learning Foundation

Begins the second neural/GNN wave with governed graph-learning snapshots, evidence-edge bindings, feature/label lineage, graph task specifications, runtime contracts, model foundations, run provenance, and non-factual predicted relationship envelopes.

## Core invariants
- GNN prediction is not a graph fact.
- A predicted relationship is never an evidence edge by default.
- High score/probability does not establish truth.
- Separate validation is required before any future evidence-edge promotion.
- Training graphs distinguish validated evidence edges from candidate/model relationships.
- Weak/heuristic labels remain advisory.
- Core defines; Workspace computes; Lab experiments; products consume.

Prepares v3.71–v3.76 without changing the evidence boundary. No database migration.
