# Platform Core v3.78.0 — Temporal Identity, Alias & Name Variant Intelligence

Introduces governed temporal identity objects layered on v3.77.0. Names, aliases, identifiers, titles, roles, and source identity assertions can carry observation time and validity intervals, supersession lineage, and unresolved temporal conflicts.

## Core boundaries
- Same name across time is not identity proof.
- Identifier reuse is not identity proof.
- Historical role/title does not establish current affiliation or authority.
- Current labels do not erase historical labels.
- Temporal overlap cannot automatically merge entities.
- Conflicting temporal assertions may coexist pending review.
- As-of views never rewrite the underlying identity graph.

Database migration: none.
