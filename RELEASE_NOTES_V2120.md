# Platform Core v2.12.0 — Country Evidence Federation & Reconciliation

v2.12.0 adds a country evidence plane on top of the v2.10.0 facility registry and v2.11.0 humanitarian fabric. It presents source families as separate evidence lanes and reconciles only genuinely comparable candidates.

Highlights:
- authority roles and source precedence for primary official, sector official, operational, intergovernmental and harmonized benchmark evidence;
- exact-concept, semantic, unit and geographic-scope comparability guards;
- material discrepancy detection without automatic averaging;
- explicit fallback when a preferred official source is absent;
- national/subnational and structural/operational separation;
- persisted reconciliation audits;
- country federation summary including facility evidence;
- public API and Python/JavaScript SDK helpers;
- WordPress country-evidence status surface;
- additive migration `0015`.

External provider health remains visible but non-blocking for Core promotion.
