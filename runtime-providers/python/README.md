# Sustainable Catalyst Python Runtime v1.0.0

Bounded CPython 3.12 provider for Platform Core v3.54.0. The provider executes only internally generated operation programs under `python3.12 -I -S`; arbitrary caller Python, shell execution, runtime package installation, caller filesystem paths, and job network access are outside the v1 contract.

Operations: descriptive_summary, linear_regression, matrix_multiply, standardize, bootstrap_mean_ci, token_frequency.
