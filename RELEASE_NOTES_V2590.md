# Platform Core v2.59.0 — Predictive Decision Intelligence

Adds additive migration `0063` and a governed predictive-decision layer connecting forecast, monitoring, spatial-temporal, and causal-predictive evidence to Decision Studio workflows.

Core owns provenance, semantic integrity, evidence bindings, handoffs, and immutable packages. Decision optimization, ranking, recommendation, utility/regret computation, constraint solving, and action execution remain outside Core.
