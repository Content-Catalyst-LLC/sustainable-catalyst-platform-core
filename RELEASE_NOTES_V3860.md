# Platform Core v3.86.0 — Contradictory Identity & Relationship Resolution

Adds governed contradiction sets across identity and relationship domains, source/provenance-aware assertion preservation, explicit resolution criteria, independent review, partial/resolved-for-handoff decisions, supersession lineage, and downstream validation handoffs.

Core never resolves contradictions by majority agreement, source count, recency, model confidence, or automatic source precedence. Resolution does not delete source history or mutate identity, relationship, or evidence graphs.

Database migration: none.
