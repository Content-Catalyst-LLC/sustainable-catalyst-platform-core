# Platform Core v3.90.0 — Unified Entity & Evidence Intelligence Runtime

Adds a single governed runtime contract across v3.77-v3.89 while preserving every upstream contract and epistemic boundary. The runtime exposes capability bindings, policy, requests, stage executions, explicit handoffs, qualified findings, deterministic execution traces, and immutable snapshots. It does not create a global truth score, auto-promote candidates, auto-resolve contradictions, accept remote references as local evidence, or mutate governed graphs.

Database migration: none.
