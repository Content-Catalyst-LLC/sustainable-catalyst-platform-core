# Platform Core v3.32.0 Audit

PASS criteria:
- controlled factors and conditions are first-class;
- experiments with conditions require a baseline;
- condition assignments reference declared factors;
- run bindings retain jobs and runtime environments;
- reproduction packages freeze exact experiment identity;
- strict component requirements support SHA-256 fingerprints;
- reproduction attempts preserve requirement-level observations;
- reproducibility assessments are descriptive provenance objects;
- Core does not execute experiments;
- Core does not choose a winning condition;
- Core does not certify scientific validity;
- no dataset/model/evaluation storage is duplicated;
- no database migration is introduced.
