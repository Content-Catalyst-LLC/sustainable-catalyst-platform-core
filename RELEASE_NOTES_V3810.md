# Platform Core v3.81.0 — Public Record & Documentary Source Object Model

- Adds governed public-record/documentary source descriptors, acquisition records, version/derivative lineage, custody events, redaction records, segment anchors, authenticity assessments, disclosure lineage, documentary evidence interpretations, and immutable snapshots.
- Separates document existence, authenticity, content, derived representations, and evidence interpretation.
- Enforces authenticity ≠ truth, redaction ≠ wrongdoing, missing/withheld material ≠ proof, and no inference of hidden content.
- Extends v3.80 source reconciliation and prepares v3.82 relationship-discovery and v3.84 evidence-chain work.
- No database migration.
