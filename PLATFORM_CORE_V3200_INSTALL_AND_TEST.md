# Platform Core v3.2.0 Install & Test

1. Push/tag the repository using `PUSH_PLATFORM_CORE_V3200_FINAL.sh`.
2. Copy the backend ZIP and `DEPLOY_PLATFORM_CORE_V3200_CONTABO.sh` to the VPS.
3. Run the deployment script.
4. Verify `/health`, `/v1/analytics/results/readiness`, and the Catalyst Analytics R provider bundle.
5. Install the WordPress v3.2.0 plugin.
