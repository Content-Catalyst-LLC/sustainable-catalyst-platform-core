# Platform Core v4.0.0 — Sustainable Catalyst Computational Research Core

v4.0.0 is the major-version consolidation of the governed Platform Core line. It retains all 43 upstream contracts from v3.57.0 through v3.99.0 and publishes a stable v4 umbrella contract and capability catalog.

## Stable domains
- Neural & Machine Learning Research Objects
- Multilingual & Linguistic Intelligence
- Graph Machine Learning & Neural Graph Reasoning
- Entity, Evidence & Investigation Intelligence
- Unified Runtime Control, Query, Session & Handoff
- Signed Artifacts, Federation Governance & Trust
- Observability, Scale & Production Certification

## Major-version guarantees
Existing contract identity, epistemic state, provenance, validation gates, original-language lineage, remote-reference boundaries, and cross-product return validation remain intact. Performance and compatibility layers may not silently change semantics or authority.

## Production status
The reference v4 package is approved for controlled soak. It deliberately carries forward the v3.99 minimum 24-hour elapsed-soak requirement and does not claim full production certification without that evidence.

Database migration: none.
