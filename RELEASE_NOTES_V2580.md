# Platform Core v2.58.0 — Causal-Predictive Integration

v2.58.0 connects the governed Predictive Intelligence object model to the existing Causal Systems Explorer without moving causal estimation or counterfactual execution into Core.

## Delivered
- additive migration `0062`;
- causal-predictive study registry bound to a predictive model and causal graph;
- governed causal-variable to predictive target/feature bindings;
- intervention-scenario manifests;
- externally computed counterfactual forecast provenance;
- causal-effect evidence and causal-predictive evaluation records;
- specialist-runtime handoffs to Lab, Workbench, Site Intelligence, and Decision Studio;
- immutable hash-chained causal-predictive packages;
- public bundle reads, Python/JavaScript SDK helpers, and WordPress status shortcode.

## Governance boundary
Platform Core does not learn causal structure, identify estimands, estimate causal effects, execute counterfactual forecasts, simulate interventions, compute causal-predictive metrics, optimize decisions, or promote outputs to truth. Those operations remain specialist-runtime responsibilities.
