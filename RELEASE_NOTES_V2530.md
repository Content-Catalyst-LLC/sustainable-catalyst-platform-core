# Platform Core v2.53.0 — Time-Series Forecasting & Backtesting

Adds governed time-series dataset references, forecast windows, baseline references, rolling/expanding backtest plans, leakage-aware folds, prediction-vs-actual records, descriptive evaluation evidence, and reproducible backtest packages. Core does not fit models, execute forecasts/backtests, compute metrics, rank models, or promote predictive output to truth.
