# v2.44.0 Audit

- Claims: explicit and source/provenance aware.
- Evidence assessments: supports / inconsistent / qualifies / neutral / unknown.
- Contradictions: explicit records with basis evidence.
- Hypotheses: competing alternatives with assumptions and disconfirming conditions.
- Matrix: descriptive, never ranked.
- Boundaries: no truth determination, probability assignment, verdict generation, guilt/responsibility attribution, or automatic contradiction detection.
