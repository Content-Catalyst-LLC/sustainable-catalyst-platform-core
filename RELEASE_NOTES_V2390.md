# Platform Core v2.39.0 — Research Librarian Visual Explanation

Adds governed research visual explanations, semantic explanation nodes and relations, citation-aware Evidence Ledger/source bindings, saved renderer-neutral views, immutable explanation snapshots, citation-coverage validation, and explicit handoffs to Research Librarian, Lab, Workbench, Site Intelligence, or external runtimes.

Core remains the semantic/provenance layer. Source retrieval, prose generation, citation selection, source ranking, analytical execution, layout, rendering, and automatic truth promotion remain outside Core.

The release also updates the Research Librarian service registry with `visual-explanations` and `citation-aware-explanations` capabilities, and aligns the Python/JavaScript public SDK download surface to the active Core release version.

Next planned Core release: **v2.40.0 — Cross-Product Visual Research Objects**.
