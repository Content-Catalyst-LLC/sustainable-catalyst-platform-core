# Release Notes — Platform Core v3.57.0

**Machine Learning & Neural Model Object Foundation**  
Contract: `sc.core.machine-learning-neural-model-object.v1`

This release establishes the governed object foundation for classical machine learning and deep learning. It extends the existing AI model registry rather than replacing it, and connects model specifications to feature schemas, objectives, declarative neural architectures, runtime adapters, datasets, computational jobs, environments, reproducible training plans, inference plans, and provenance.

No model fitting or inference is performed by Platform Core in v3.57.0.
