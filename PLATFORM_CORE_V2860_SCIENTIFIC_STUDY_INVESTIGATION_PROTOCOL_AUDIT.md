# Platform Core v2.86.0 — Scientific Study & Investigation Protocol Model

Adds a universal, provenance-aware protocol object for experimental studies, observational studies, engineering investigations, forensic investigations, literature/systematic reviews, mixed-method research, simulations, and case studies. Protocols can declare questions, objectives, scope/population/system/case units, variables/measures, data/source plans, acquisition and sampling, analytical methods, assumptions, validation/challenge plans, reproducibility requirements, ethics/governance metadata, planned outputs, deviations, revisions, lineage, and immutable snapshots.

Core records planned research structure. It does not execute studies, recruit or randomize participants, collect data/evidence, run analyses, compute or infer results, infer causality, judge methodological quality, certify ethics, approve protocols, or infer truth.
