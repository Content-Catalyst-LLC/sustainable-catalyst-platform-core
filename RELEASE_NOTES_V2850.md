# Platform Core v2.85.0 — Research Portfolio & Institutional Knowledge Governance

Adds an institutional portfolio layer above v2.84 research programs. Core stores declared portfolio membership, themes, objectives, program dependencies, resource envelopes, risks, reviews, governance decisions, revision history, provenance lineage, and immutable snapshots.

## Governance boundary
Core does not rank or score programs, choose priorities, allocate resources/funding, optimize portfolios, make governance decisions, infer strategic value, forecast program success, close risks, or infer truth.
