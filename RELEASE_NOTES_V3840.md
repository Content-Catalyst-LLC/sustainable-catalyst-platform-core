# Platform Core v3.84.0 — Explainable Connection Paths & Evidence Chains

v3.84.0 adds provenance-preserving connection paths and explicit evidence-chain objects over the v3.83 network intelligence layer.

Highlights:
- epistemic-state-preserving path steps;
- reproducible explainable connection paths;
- evidence-chain items with source-independence groups;
- contradiction markers that preserve upstream reconciliation conflicts;
- alternative-path comparison without false independence claims;
- path bottleneck records for uncertainty/provenance limitations;
- immutable connection-path evidence snapshots;
- no automatic relationship promotion, evidence-edge creation, or graph mutation.

Contract: `sc.core.explainable-connection-paths-evidence-chains.v1`

Public endpoint: `/public/v1/connection-paths/contract`

Database migration: none.
