# Platform Core v2.46.0 — Forensic Spatial/Temporal Evidence Integration

Adds migration 0050 and governed spatial/temporal forensic evidence semantics: places, evidence/location bindings, event/place bindings, uncertainty envelopes, trajectory evidence, explicit spatial-temporal intersections, linked map-timeline views, Site Intelligence handoffs, and immutable snapshots. Core remains renderer-neutral and does not perform CRS reprojection, spatial joins, routing, remote sensing, or automatic location-truth determination.
