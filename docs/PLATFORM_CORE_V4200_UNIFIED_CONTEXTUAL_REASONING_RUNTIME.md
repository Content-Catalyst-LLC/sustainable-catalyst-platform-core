# Platform Core v4.20.0 — Unified Contextual Reasoning Runtime

## Purpose
Consolidate v4.11 through v4.19 into one governed contextual-reasoning runtime and auditable end-to-end trace.

## Governed sequence
1. Contextual Memory
2. Retrieval & Relevance
3. Claim Alignment / Agreement / Contradiction
4. Evidence-Context Integration
5. Contextual Causal Language & Mechanisms
6. Narrative / Framing / Perspective
7. Cross-Source Semantic Reconciliation
8. Contextual Hypotheses / Competing Explanations
9. Semantic Synthesis / Research Answer

## Boundaries
Runtime completion does not establish truth. Synthesis answers do not become evidence records. Scores or confidence labels are not probabilities. No automatic evidence promotion, hypothesis selection, canonical identity merge, or graph mutation is authorized.

## Milestone
This release completes the planned v4.11–v4.20 contextual-reasoning arc and is the recommended Core feature-expansion stopping point while product surfaces integrate the governed runtime.

Database migration: none.
