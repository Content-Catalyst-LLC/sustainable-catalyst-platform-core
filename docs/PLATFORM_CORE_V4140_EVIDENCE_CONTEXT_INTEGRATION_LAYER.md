# Platform Core v4.14.0 — Evidence-Context Integration Layer

## Purpose
Bridge contextual semantic claims and claim-comparison assessments to governed evidence objects without promoting semantic interpretation into evidence truth.

## Core boundaries
- Semantic claims and evidence records remain distinct.
- Upstream Evidence Ledger review status is authoritative.
- Same-source translations cannot count as independent corroboration.
- Contradiction is not resolved by evidence-link counts.
- The v4.14 reference integration performs no graph mutation and no automatic evidence materialization.
