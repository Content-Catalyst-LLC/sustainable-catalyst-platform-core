# Platform Core v3.56.0 — JVM Runtime

Establishes OpenJDK 21 / JVM as a first-class governed execution target. The provider exposes bounded JVM operations through provider-generated Java bootstrap programs while prohibiting caller-supplied bytecode, source, classpaths, dependency installation, shell access, and network access.

Java, Kotlin and Scala language profiles are intentionally deferred to v3.56.1. Spark is intentionally deferred to v3.56.2.
