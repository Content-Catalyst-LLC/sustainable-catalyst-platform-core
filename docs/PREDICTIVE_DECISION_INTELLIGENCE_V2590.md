# Predictive Decision Intelligence v2.59.0

Platform Core v2.59.0 provides governed, provenance-aware decision-support objects above forecasting, monitoring, spatial-temporal prediction, and causal-predictive evidence.

Core records decision studies, options, criteria, evidence bindings, externally computed scenario assessments and evaluation evidence, specialist-runtime handoffs, and immutable packages. It does not compute utilities or regret, rank/recommend options, optimize policies, solve constraints, execute actions, or automatically select interventions.
