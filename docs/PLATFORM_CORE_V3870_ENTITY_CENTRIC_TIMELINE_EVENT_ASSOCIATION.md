# Platform Core v3.87.0 — Entity-Centric Timeline & Event Association

Contract: `sc.core.entity-centric-timeline-event-association.v1`

v3.87 creates provenance-preserving entity timelines and event associations above v3.86 contradiction resolution. Events retain assertion state, source anchors, temporal precision/uncertainty, entity roles, and contradiction context.

## Boundaries
- Temporal proximity is not causality.
- Co-presence is not relationship proof.
- Sequence is not intent.
- Repeated association is not coordination.
- Timeline ordering is a view over asserted event time, not a causal ordering.
- Omission from a timeline does not establish nonoccurrence.
- No identity, relationship, or evidence graph mutation occurs in v3.87.

Database migration: none.
