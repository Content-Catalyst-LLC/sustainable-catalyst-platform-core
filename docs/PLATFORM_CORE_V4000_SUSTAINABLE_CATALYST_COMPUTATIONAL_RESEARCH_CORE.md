# Platform Core v4.0.0 — Sustainable Catalyst Computational Research Core

## Purpose
Provide a stable major-version computational research Core over the governed v3 contract stack without flattening contract identity or epistemic distinctions.

## Architecture
Core defines governed objects, contracts, orchestration, provenance, integrity, query/session state, federation policy, observability, and scale controls. Specialist products and runtimes compute or render within those contracts.

## Epistemic boundary
A major-version transition, stable API label, cache hit, model output, graph inference, federation signature, or cross-product handoff never establishes truth or automatically creates evidence.

## Production readiness
The v4.0 reference bundle is approved for controlled soak and carries forward the v3.99 minimum 24-hour elapsed-soak requirement.
