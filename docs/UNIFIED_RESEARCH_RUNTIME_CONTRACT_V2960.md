# Unified Research Runtime Contract — v2.96.0

The runtime contract provides a stable cross-product integration boundary for Library, Research Librarian, Workspace, Research Lab, Workbench, Site Intelligence, Decision Studio, Catalyst Data, and external systems.

The contract is reference-first and provenance-preserving. Specialist products continue to own specialist execution and user experience; Platform Core owns shared declarations, exchange lineage, compatibility evidence, and immutable state.
