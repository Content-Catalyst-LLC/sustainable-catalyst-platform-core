# Open Forensics — Forensic Object Model & Evidence Provenance v2.42.0

Platform Core provides a governed forensic semantic layer for investigations, objects, evidence provenance, source bindings, and immutable snapshots. It is designed for transparent, reproducible inquiry across Sustainable Catalyst.

## Boundaries

The v2.42 layer records source and hash metadata. It does not establish legal chain of custody; custody events, transfers, seals, and integrity attestations are reserved for v2.43. Core also does not infer authenticity, authorship, identity, responsibility, causation, guilt, or legal conclusions.
