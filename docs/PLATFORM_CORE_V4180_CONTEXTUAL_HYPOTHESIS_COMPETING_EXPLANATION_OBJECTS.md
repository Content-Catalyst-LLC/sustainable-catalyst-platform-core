# Platform Core v4.18.0 — Contextual Hypothesis & Competing Explanation Objects

Platform Core v4.18.0 adds a governed hypothesis layer over v4.17 cross-source semantic reconciliation. It represents multiple live explanations for the same reconciled source context without forcing premature resolution.

## Governance boundary

A hypothesis is an explanatory object, not a truth claim. Explanatory-fit scores are not probabilities, evidence weights, or credibility scores. Supporting positions do not establish truth, challenging positions do not establish falsity, and retained hypotheses are not selected winners. Original-language authority, translation derivation, source independence, causal-identification limits, identity uncertainty, unresolved scope, and cross-source conflicts carry forward unchanged.

## Reference inventory

The deterministic reference bundle contains 10 contextual hypotheses, 12 evidence positions, 7 pairwise explanation comparisons, 4 competing-explanation sets, one provenance record, and one supersedable snapshot. It covers alternative explanations for emissions disagreement, ministry/agency identity, cross-language governance terminology, and Chinese/English cost-claim agreement.

## Mutation boundary

No automatic hypothesis promotion and no Context Graph, Evidence Graph, Knowledge Graph, or Identity Graph mutation is authorized or performed.

Database migration: none.
