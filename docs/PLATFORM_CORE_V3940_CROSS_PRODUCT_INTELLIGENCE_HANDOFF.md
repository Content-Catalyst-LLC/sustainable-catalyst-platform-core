# Platform Core v3.94.0 — Cross-Product Intelligence Handoff Contract

Contract: `sc.core.cross-product-intelligence-handoff.v1`

This release defines contract-preserving, provenance-aware handoffs from Platform Core research sessions into Workspace, Knowledge Library, Research Librarian, Research Lab, Workbench, Site Intelligence, and Decision Studio. Receiving products must preserve source contract identity, epistemic and validation states, provenance, contradictions, remote-reference boundaries, and review/validation gates. Handoff acceptance is not content validation or a truth assessment. Returned outputs are derived objects requiring explicit validation/merge before any epistemic promotion.

No database migration.
