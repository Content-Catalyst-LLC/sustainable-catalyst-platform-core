# Platform Core v3.75.0 — Knowledge Graph Representation Learning

Defines provenance-governed knowledge-graph representation-learning objects for entity/relation spaces, scoring functions, negative sampling, triple scoring, and ranking evaluation. Core remains non-compute. Representation scores never establish facts, evidence, identity, or relationships. Negative samples are training artifacts rather than false facts. This release prepares v3.76 evidence-graph neural analysis and validation workflows.
