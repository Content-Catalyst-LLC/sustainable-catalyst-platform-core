# Platform Core v2.50.0 — Forensic Research Graph

A governed, renderer-neutral cross-forensics graph for explicit references across evidence, objects, custody, claims, hypotheses, events, places, media, quantitative reconstruction, testimony/documentary evidence, research models/results, Core entities, and external product references.

Core stores explicit nodes, evidence-backed edges, saved views, handoff manifests, immutable snapshots, and portable graph packages. It does not infer identity, causation, proof, authenticity, probability, verdict, guilt, responsibility, or truth from graph topology.
