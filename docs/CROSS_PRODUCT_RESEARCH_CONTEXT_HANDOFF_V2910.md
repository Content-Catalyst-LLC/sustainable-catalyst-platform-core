# Platform Core v2.91.0 — Cross-Product Research Context & Handoff Protocol

Defines a stable context envelope and governed handoff contract for moving research work across Sustainable Catalyst products without losing provenance or state. Context may bind projects, workflow stages, protocols, evidence, datasets, methods, executions, findings, claims, inferences, audits, reviews, publications, visualizations, forensic objects, and predictive objects.

Core records declared routes and packages, checks explicit required-binding completeness, computes deterministic package integrity hashes, records acknowledgements/conflicts, and preserves revision/snapshot lineage. Core does not autonomously choose destinations, execute or dispatch handoffs, mutate source objects, infer missing context, resolve conflicts, authorize access, infer scientific validity, or determine truth.
