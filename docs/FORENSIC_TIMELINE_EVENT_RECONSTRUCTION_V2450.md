# Platform Core v2.45.0 — Forensic Timeline & Event Reconstruction

This release adds evidence-linked forensic events, bounded temporal assertions, participant references, explicit temporal/event relations, competing event reconstruction hypotheses, saved timeline views, renderer-neutral timeline specifications, and immutable timeline snapshots.

A reconstruction is a governed hypothesis, not a determination of historical truth. Core does not infer missing events or timestamps, resolve participant identity, rank reconstructions, assign probabilities, generate verdicts, or automatically promote a reconstructed sequence to truth.
