# Platform Core v2.92.0 — Research Project State, Versioning & Reproducibility

Creates immutable, hash-linked project-state versions that reference exact research objects, object versions/hashes, dependencies, software/runtime environments, named checkpoints, reconstruction plans, externally supplied verification evidence, revision history, and immutable project snapshots.

Core can reconstruct a historical **manifest of declared state**. It does not fetch missing artifacts, replay analyses, restore an application, infer reproducibility, certify scientific validity, choose a canonical state, or determine truth.
