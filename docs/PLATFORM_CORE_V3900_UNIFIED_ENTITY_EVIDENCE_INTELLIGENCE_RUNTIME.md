# Platform Core v3.90.0 — Unified Entity & Evidence Intelligence Runtime

Contract: `sc.core.unified-entity-evidence-intelligence-runtime.v1`

This release consolidates the governed entity/evidence intelligence line from v3.77 through v3.89 behind a single orchestration contract. It does not replace or flatten the upstream contracts. Each stage retains its own contract identity, provenance, epistemic state, contradiction state, validation requirements, and promotion boundaries.

## Runtime stages

1. Entity resolution
2. Temporal identity
3. Probabilistic record linkage
4. Cross-source reconciliation
5. Documentary source intelligence
6. Relationship discovery
7. Network structure/community/motif intelligence
8. Explainable connection paths/evidence chains
9. Multi-hop graph reasoning
10. Contradictory identity/relationship resolution
11. Entity-centric timelines
12. Reproducible graph investigation packages
13. Federated evidence graph exchange

## Non-negotiable boundaries

- No global truth score.
- No automatic candidate/hypothesis promotion.
- No automatic contradiction resolution.
- Analytical confidence is not probability of truth.
- Completed runtime execution is not truth certification.
- Remote acceptance is not local evidence.
- No identity, relationship, or evidence graph mutation.

Database migration: none.
