# Reproducible Visual Knowledge Layer — v2.41.0

Platform Core v2.41.0 turns cross-product visual research objects into reproducibility-aware knowledge artifacts. It records explicit source inputs and versions, optional SHA-256 content hashes, runtime environments, dependency and container references, random seeds, replay plans, verification evidence, immutable snapshots, and portable reproducibility manifests.

Core performs semantic packaging, hashing, provenance capture, integrity checks, and verification-record governance. Specialist computation, GIS/remote sensing, model execution, arbitrary code execution, replay execution, and output-equivalence claims require the declared external runtimes or human verification.
