# Claims, Contradictions & Competing Hypotheses — v2.44.0

Adds governed forensic claims, explicit evidence-position assessments, contradiction records, alternative/competing hypotheses, descriptive evidence-hypothesis matrices, hypothesis relations, and immutable reasoning snapshots.

Core records and compares explicit assessments. It does not automatically detect contradictions, determine truth, assign hypothesis probabilities, rank hypotheses, generate verdicts, or promote conclusions to truth.
