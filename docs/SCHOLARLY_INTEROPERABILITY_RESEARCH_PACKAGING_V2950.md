# Scholarly Interoperability & Research Packaging — v2.95.0

Core records declared scholarly-package structure and interoperability metadata across citations, persistent identifiers, datasets, notebooks, provenance manifests, metadata standards, export profiles, publication bindings, and external validation evidence. It does not mint/register identifiers, submit/publish research, execute notebooks, transform datasets, certify reproducibility, validate scientific content, infer authorship, or determine truth.
