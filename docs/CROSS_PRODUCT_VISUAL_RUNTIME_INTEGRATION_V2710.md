# Cross-Product Visual Runtime Integration

v2.71.0 exposes the v2.70 Unified Visual Reasoning Engine as a shared semantic runtime across Sustainable Catalyst products.

A canonical research object can now be bound to product-local representations while retaining one Core identity and provenance path. Product integrations declare supported capabilities and external operation/result contracts. Handoff routes describe how a request moves between products; Core records the route but does not execute it. Synchronization records preserve hashes and evidence about cross-product state alignment without automatically mutating either side.

This allows, for example, one Library source document to remain the same governed object when displayed in a graph, mapped through Site Intelligence, analyzed in Lab/Workbench, discussed in a Workspace notebook, or incorporated into Decision Studio.
