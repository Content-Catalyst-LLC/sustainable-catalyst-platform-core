# Platform Core v4.15.0 — Contextual Causal Language & Mechanism Intelligence

This release extends the v4.14 Evidence-Context Integration Layer with governed causal-language interpretation and mechanism objects.

## New governed objects
- CausalLanguageSignal
- MechanismHypothesis
- InterventionContext
- CounterfactualContext
- CausalAssessment
- CausalProvenanceRecord
- CausalSemanticSnapshot

## Epistemic boundary
Causal wording is not causal identification. Temporal precedence and association are not causality. Mechanism plausibility is not mechanism validation. Intervention language is not experimental evidence. Counterfactual questions are not counterfactual effect estimates.

## Persistence
No database migration. No automatic causal, evidence, knowledge, or identity graph mutation.
