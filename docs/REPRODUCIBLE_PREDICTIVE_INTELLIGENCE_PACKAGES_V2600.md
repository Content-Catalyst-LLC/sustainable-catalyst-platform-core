# Reproducible Predictive Intelligence Packages — v2.60.0

v2.60.0 provides a cross-layer, provenance-preserving package that can bind governed predictive objects and external artifacts into an immutable review/reproduction manifest. The package records what was used, where it came from, the runtime environment, verification evidence, review evidence, and successive content hashes.

The package is deliberately non-executing. Reproduction plans are carried as evidence and environment metadata; specialist runtimes remain responsible for computation.
