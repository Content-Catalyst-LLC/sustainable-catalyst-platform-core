# Predictive Model Object Model & Forecast Provenance — v2.52.0

Platform Core governs predictive model identity, targets, feature/source provenance, training-window manifests, forecast issue/horizon records, observations, descriptive evaluation evidence, specialist-runtime handoffs, and immutable forecast snapshots. Core does not fit models or execute inference. Probabilistic calibration, ensembles, anomaly detection, spatial-temporal prediction, causal-predictive integration, decision intelligence, and reproducible predictive packages are later releases.
