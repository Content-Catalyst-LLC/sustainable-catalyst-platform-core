# Research Notebook & Analytical Narrative — v2.76.0

Contract: `sc.research.notebook-narrative.v1`.

The notebook is a project-scoped research record with ordered sections and entries. Entries can bind explicitly to methodology versions, analysis runs and outputs, datasets, evidence, findings, visualizations, lineage graphs, and reproducibility packages. Citations remain declared source references. Analytical narratives are ordered researcher-authored blocks with explicit support references and uncertainty metadata.

Platform Core stores and traces this material. It does not execute notebook code, run analyses, generate narrative, fabricate citations, infer conclusions, alter bound artifacts, or publish research automatically.
