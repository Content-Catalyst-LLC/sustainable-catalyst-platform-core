# Platform Core v3.88.0 — Reproducible Graph Investigation Package

Contract: `sc.core.reproducible-graph-investigation-package.v1`

This release packages governed graph-investigation state into a content-addressed, portable, reproducible unit. It preserves object identity, fingerprints, epistemic state, provenance, contradictions, timelines, evidence paths, reasoning traces, documentary anchors, environment metadata, replay steps, and verification qualifications.

Reproducibility is not a truth, authenticity, admissibility, correctness, or completeness verdict. Package replay is non-mutating.

Database migration: none.
