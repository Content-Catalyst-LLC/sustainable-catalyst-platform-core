# Platform Core v3.97.0 — Unified Runtime Observability, Audit & Drift Intelligence

Contract: `sc.core.unified-runtime-observability-audit-drift-intelligence.v1`

This release adds a governed diagnostic plane over the unified Core runtime. It records runtime and contract health, immutable audit events, provenance gaps, explicit drift baselines and observations, stale-evidence signals, federation-policy drift, SLO indicators, alert decisions, traces, and immutable supersedable snapshots.

## Epistemic boundaries

Operational anomalies and drift do not establish the truth or falsity of research claims. Staleness triggers revalidation rather than deletion. Alerts never promote or demote epistemic state and do not mutate identity, relationship, or evidence graphs.

Database migration: none.
