# Platform Core v2.72.0 — Unified Research Project Object Model

Contract: `sc.research.unified-project.v1`

This release promotes the existing v2.28 `research-project` identity into the shared research substrate for Sustainable Catalyst. It does not replace existing `project_entity_id` references.

## Governed records
- unified project profiles
- research questions
- objectives
- typed project components: literature, source collections, datasets, evidence, methodology, models, analysis runs, findings, visualizations, investigations, conclusions, limitations, unresolved questions
- explicit research relationships
- provenance records
- specialist runtime handoffs
- immutable hash-chained snapshots

Core preserves semantics, provenance and reproducible state. Specialist products perform computation, analysis and rendering. Core does not infer originality or promote findings/conclusions automatically.
