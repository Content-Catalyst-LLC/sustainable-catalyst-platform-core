# Platform Core v2.63.0 — Analytical Visualization Grammar

Adds a renderer-neutral declarative visualization grammar above v2.61 scene graphs and v2.62 coordinated view composition. Governed objects cover specifications, data bindings, marks, encodings, scales, transforms, guides, and immutable hash-chained snapshots. The grammar supports cartesian, polar, matrix, network, timeline, flow, geospatial, causal, layered, dashboard, and custom views.

Core stores declarative grammar and provenance only. It does not execute transforms or aggregation, calculate scales/layout, draw marks, run GPU code, generate charts automatically, or infer truth from visual appearance.
