# Platform Core v2.81.0 — Reproducible Research Publication & Scholarly Output Engine

Database migration: `0085`.

Adds governed publication objects, structured manuscript sections, bibliographic reference and citation traceability, figure/table and supplement registries, external identifier records, structural publication-readiness diagnostics, research-to-publication lineage, export manifests, revisions, and immutable snapshots. Core records researcher-authored scholarly outputs and declared provenance; it does not generate conclusions, fabricate citations, judge or certify publication quality, issue DOIs, infer truth, or publish externally.
