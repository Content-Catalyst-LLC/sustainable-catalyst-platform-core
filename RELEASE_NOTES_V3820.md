# Platform Core v3.82.0 — Relationship Discovery & Connection Hypothesis Objects

Adds governed source-observed relationships, relationship-discovery signals, connection candidates, explicit hypotheses, evidence positions, independent reviews, promotion gates, and immutable snapshots. The release preserves the distinction between analytical association and factual relationship: co-occurrence, shared attributes, graph proximity, embedding similarity, source count, and model scores cannot establish a relationship or create an evidence edge. Separate evidence validation is required before any downstream graph mutation.

Database migration: none.
