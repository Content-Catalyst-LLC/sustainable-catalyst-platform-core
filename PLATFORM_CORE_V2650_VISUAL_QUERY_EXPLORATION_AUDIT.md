# v2.65.0 Visual Query & Exploration Audit

## Core owns
- exploration sessions and target registries
- declarative query/predicate/traversal contracts
- external result/evidence bindings
- saved exploration state
- immutable hash-chained query snapshots

## Core does not own
- query execution
- graph traversal
- data retrieval/filtering/aggregation
- result ranking/recommendation
- visual inference or truth promotion
