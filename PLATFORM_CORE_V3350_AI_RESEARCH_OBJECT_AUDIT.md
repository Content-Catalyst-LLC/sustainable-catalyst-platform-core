# Platform Core v3.35.0 Audit

PASS criteria:
- eight AI Engineering contracts are registered in one manifest;
- source contracts remain authoritative;
- source payloads are referenced rather than copied;
- object IDs are unique in the unified registry;
- source contract must match object kind binding;
- relationship endpoints must exist in the graph;
- relationship contracts use the v3.35 unified contract;
- upstream/downstream lineage traversal is deterministic;
- lineage filters and depth limits are explicit;
- snapshot fingerprints bind manifest/registry/graph;
- packages can select only registered objects/relationships;
- product ownership boundaries are preserved;
- Core does not execute jobs, choose models or certify validity;
- no database migration is introduced.
