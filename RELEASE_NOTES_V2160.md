# Platform Core v2.16.0 — Governance, Access & Audit Control Plane

Adds central policy decisions, scoped principal roles, visibility ceilings, deny-wins conflict handling, persisted decision records, SHA-256-linked audit events, secret redaction, retention controls, public-safe readiness, WordPress status, and SDK readiness helpers. Governance is introduced in `audit` mode by default to avoid accidental first-party lockout. Evidence authority/provenance semantics are unchanged. Migration: 0019.
