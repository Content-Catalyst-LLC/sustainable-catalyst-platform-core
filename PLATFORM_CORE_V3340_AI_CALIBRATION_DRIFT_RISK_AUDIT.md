# Platform Core v3.34.0 Audit

PASS criteria:
- calibration bins and metrics retain exact model/evaluation lineage;
- calibration thresholds are explicit;
- monitoring windows are stable research objects;
- drift signal identity and implementation hash are supported;
- baseline/comparison windows are distinct;
- drift severity and threshold state are explicit;
- risk indicators preserve category and threshold semantics;
- risk observations bind source objects/evidence;
- monitoring policy does not imply Core scheduling;
- monitoring snapshots integrate v3.33 robustness/error-analysis objects;
- Core does not autonomously retrain or block models;
- Core does not certify model safety or operational readiness;
- no database migration is introduced.
