# Sustainable Catalyst Platform Core v2.14.0

## Cross-Product Evidence Exchange

v2.14.0 adds a governed, provenance-preserving handoff plane for exchanging canonical evidence and analytical references across Sustainable Catalyst products.

Highlights:

- persisted exchange packages, items, and receipt history;
- reference-first canonical Core URIs;
- optional bounded snapshots with secret-field rejection;
- public/private visibility guardrails;
- idempotent package creation;
- pull/acknowledgement delivery semantics;
- receipt states for acknowledgement, acceptance, rejection, and derivation;
- private reliability events for package creation and receipt updates;
- no automatic Truth promotion, ownership transfer, source mutation, or cross-product delivery;
- public readiness surface without package-data exposure;
- Python and JavaScript SDK readiness helpers;
- additive migration `0017`.
