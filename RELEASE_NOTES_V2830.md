# Platform Core v2.83.0 — Cross-Study Evidence Synthesis & Meta-Research

Database migration: `0087`.

Adds governed cross-study synthesis protocols, declared study inclusion/exclusion, harmonized outcomes, source-reported or externally computed effect records, externally computed meta-analysis result provenance, meta-research assessments, cross-study relations, evidence-gap records, revision history, descriptive summaries, declared lineage, and immutable snapshots. Core does not search literature, decide inclusion, calculate effect sizes, pool estimates, score study quality, infer bias or causality, rank evidence, generate conclusions, or infer truth.
