# v2.87.0 Audit — Computation, Analysis & Execution Lineage

## Governed records
Executions, versioned inputs, parameters, assumptions, software environments, ordered execution steps, outputs, research-object bindings, cross-execution dependencies, verification evidence, revisions, declared lineage, and immutable hash-chained snapshots.

## Authority boundary
The layer is provenance infrastructure. It records externally produced computation and evidence but does not execute code or specialist runtimes, transform data, compute statistics, train/fit models, generate outputs, infer findings/claims, validate results, infer reproducibility, or infer truth.
