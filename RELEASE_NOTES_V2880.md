# Platform Core v2.88.0 — Unified Findings, Claims & Inference Engine

Adds a unified inference-semantics layer above the existing finding, interpretation, claim, hypothesis, argument, conclusion, protocol, computation-lineage, evidence, publication, replication, and synthesis objects.

The release distinguishes observation, measurement, descriptive finding, statistical association, statistical inference, causal inference, model-derived result, prediction, forecast, interpretation, expert judgment, hypothesis, speculation, and conclusion. Classifications and confidence are researcher-declared; Core does not infer, score, rank, validate, resolve contradictions, or determine truth.
