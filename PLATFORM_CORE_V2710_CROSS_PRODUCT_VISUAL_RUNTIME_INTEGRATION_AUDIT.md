# v2.71.0 Cross-Product Visual Runtime Integration Audit

The release creates eight additive persistence families:
1. `cross_product_visual_runtime_integrations`
2. `cross_product_visual_object_bindings`
3. `cross_product_visual_context_bindings`
4. `cross_product_visual_capability_bindings`
5. `cross_product_visual_view_bindings`
6. `cross_product_visual_handoff_routes`
7. `cross_product_visual_sync_records`
8. `cross_product_visual_integration_snapshots`

Supported product keys are `library`, `lab`, `workbench`, `decision-studio`, `site-intelligence`, `workspace`, and `research-librarian`.

The Core boundary is declarative. Rendering, computation, product-state mutation, handoff execution, and automatic synchronization stay in specialist products/runtimes.
