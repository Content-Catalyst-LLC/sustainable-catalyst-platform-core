# Platform Core v2.38.0 — Spatial & Temporal Visual Reasoning

Adds first-class spatial-temporal scenes, governed GeoJSON features, temporal events and intervals, trajectories, change observations, saved views, renderer-neutral linked map/timeline specifications, and explicit runtime handoffs to Site Intelligence, Lab, Workbench, or external compute.

Core remains the semantic/provenance layer. Heavy GIS, raster, remote-sensing, routing, and arbitrary temporal computation remain outside Core.
