# Platform Core v3.37.0 Audit

PASS criteria:
- statistical plan identity is first-class;
- exact dataset and variable bindings are preserved;
- method specification is explicit and researcher-declared;
- hypotheses and alpha are reproducible;
- estimates, intervals, tests, effects and fit statistics are governed objects;
- diagnostics and assumption checks remain explicit evidence;
- matrix-valued statistical results are supported;
- runtime/job/environment lineage is first-class;
- all six R Runtime 1.0 operations normalize into Core objects;
- raw runtime results remain traceable;
- Core does not execute or choose statistical methods;
- Core does not convert significance into truth;
- Core does not certify assumptions or statistical validity;
- no database migration is introduced.
